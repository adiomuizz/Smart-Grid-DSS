# Smart Grid Decision Support System (SG-DSS)

## Overview
A research prototype for analysing electricity distribution
performance, technical losses, non-technical losses, and
ATC&C loss-reduction interventions in Nigeria.

## Research Modules
- Technical-loss simulation using pandapower
- Non-technical-loss detection experiments
- ATC&C performance analysis
- Decision-support visualisations

## Installation
Create and activate a Python virtual environment, then run:

    python -m pip install -r requirements.txt

## Status
Research prototype under development.
